# 影院管理系统 (TTMS - Theater Ticket Management System)

## 项目简介

影院管理系统是一个基于C语言开发的控制台应用程序，用于管理影院的日常运营，包括影厅管理、剧目管理、演出计划安排、票务管理和销售统计等功能。

## 系统架构

系统采用分层架构设计，包含以下层次：

- **表示层 (View)**：用户界面、菜单、输入输出、控制台交互
- **业务层 (Service)**：业务逻辑、数据处理、权限控制、业务流程
- **持久层 (Persistence)**：数据存储、文件操作、数据读写
- **工具层 (Common/SafeStdin)**：通用数据结构、链表、安全输入、工具函数

## 核心功能模块

### 1. 账户管理

- 支持三种用户角色：管理员、经理、售票员
- 登录验证和权限控制
- 自动登录功能

### 2. 影厅管理

- 影厅信息的增删改查
- 座位布局管理

### 3. 剧目管理

- 剧目信息的增删改查
- 支持不同类型剧目（电影、歌剧、音乐会）
- 支持不同分级（儿童、青少年、成人）

### 4. 演出计划

- 创建和管理演出计划
- 关联剧目和影厅
- 演出状态管理

### 5. 票务管理

- 票的生成和管理
- 票状态跟踪（可售、已售、预留）
- 座位管理

### 6. 售票系统

- 售票流程管理
- 销售记录跟踪
- 交易时间记录

### 7. 统计分析

- 销售数据统计
- 票房排行榜

### 8. 查询功能

- 多维度数据查询
- 支持按不同条件筛选

## 技术特点

- **C语言开发**：使用标准C语言编写，兼容多种编译器
- **分层架构**：清晰的代码组织结构，便于维护和扩展
- **链表数据结构**：使用双向循环链表管理数据集合
- **安全输入处理**：专门的安全输入模块防止输入错误和缓冲区溢出
- **权限控制**：基于角色的访问控制（RBAC）
- **文件持久化**：使用文件系统存储数据
- **分页显示**：支持大数据集合的分页浏览

## 安装与运行

### 编译方法

1. 使用支持C语言的编译器（如GCC、MSVC等）
2. 编译所有源文件

### 运行环境

- 支持Windows、Linux等操作系统
- 需要标准C库支持

### 首次运行

系统会自动创建默认管理员账户：

- 用户名：admin
- 密码：123123123

## 使用指南

1. 启动程序后，系统会尝试自动登录
2. 如果自动登录失败，会显示登录界面
3. 登录后进入主菜单，根据用户角色显示不同的功能选项
4. 通过菜单选择进行相应的操作
5. 按E键退出系统

### 角色权限说明

| 角色  | 权限范围                              |
| --- | --------------------------------- |
| 管理员 | 所有功能（包括账户管理）                      |
| 经理  | 影厅查询、剧目管理、创建计划、售票、查询、统计分析、管理售票员账户 |
| 售票员 | 查询影厅、查询剧目、售票、查询票信息、查询座位           |

## 数据存储

系统使用文件存储数据，每个实体类型对应一个数据文件。数据文件会在首次运行时自动创建。

## 安全注意事项

1. 密码以明文形式存储在文件中，仅用于教学目的
2. 生产环境中应使用密码加密存储
3. 系统未实现网络功能，所有操作均在本地执行
